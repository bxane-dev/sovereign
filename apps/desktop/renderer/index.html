Set up plugins

Add MCP servers to the config file below, then restart Sovereign. Each plugin tool requires your approval before a model can use it.

{
  "mcp_servers": [
    { "name": "my-plugin", "command": ["program", "arg"], "enabled": true }
  ]
}

Plugin installation and discovery are not built into this version yet.
